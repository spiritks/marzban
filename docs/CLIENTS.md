# Client provisioning

Give users only the Marzban subscription link.

Recommended clients:

- Windows: Hiddify Next, v2rayN, Nekoray
- Android: Hiddify Next, v2rayNG
- iOS: Streisand, FoXray, Shadowrocket
- macOS: Hiddify Next, Nekoray, Streisand

Basic support script for users:

1. Install client.
2. Import subscription URL.
3. Update subscription.
4. Select nearest node.
5. Connect.
6. Open an IP check site and verify country/IP changed.

If DNS does not work on Windows, check whether the client forced DNS on a TUN/tun2socks interface and whether local DNS is still reachable.
